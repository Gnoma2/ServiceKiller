# Compatibility

## Validated

ServiceKiller V1.1.3.01 has been functionally validated on:

- **Windows 11 Pro 25H2**
- **Build 26200**
- **x64**
- .NET Framework 4.8 runtime

## Not currently validated

- Windows 10
- Windows Server
- Windows 8 / 8.1
- Windows 7
- ARM64 Windows

“Not validated” does not necessarily mean “known incompatible”; it means the project does not currently make a public compatibility claim for that platform.

## Scope of the validation claim

The validation claim applies to the current tweak catalog and restoration architecture tested on the configuration above. Windows services and optional components vary by edition, installed features and future Windows updates, so the program intentionally treats missing services as unavailable/omitted rather than assuming they exist.
