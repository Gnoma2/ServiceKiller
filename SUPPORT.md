# Support

For normal bugs, compatibility reports and feature requests, use GitHub Issues and the provided issue templates.

Before filing an issue:

1. Confirm the issue occurs with the latest public release.
2. Include the Windows edition/version/build.
3. Describe whether the mode was Persistent or Temporary.
4. Include the anonymized diagnostic if relevant, **after reviewing it manually for private information**.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
